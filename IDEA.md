# Intro

## What i want
- I want to have a Chrome extension that allows the user who has that one installed to operate on a certain type the user selected only, ideally. 
- It should then allow, through communication with some backend system or similar, to get information and allow access to information on that page and control the page. 

## Security and trust
- I would, though, like to have a Chrome extension that is purely built for this interactive purpose and security and trust, so that, for example, companies can have an easier time allowing it within their corporations.
